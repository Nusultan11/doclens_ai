## Data separation and acquisition

`extraction_corpus_v2_manifest.json` is a separate versioned **60-document Office
pilot manifest**, with opaque asset IDs, hashes, rights provenance references and
unknown languages. Its seven target units remain separate; the other five targets
are incomplete. The schema is generated by `Corpus.model_json_schema()` in
`src/doclens_ai/eda/corpus_v2.py`. Actual files and detailed acquisition ledgers
are private/ignored; original filenames, URLs and content are not in this manifest.
No v1 bytes, manifests, historical Gold or reviewed attestations are rewritten.

`extraction_v2_dataset_qualification.json` freezes five repository revisions and
the obtained metadata/card hashes. Its acquisition events distinguish metadata
requests from payload attempts. Payload downloads for those five datasets: zero. Dataset-card
licenses and original-document rights are separate fields; permission to run
local evaluation and use annotations must be established before admission.
Research-only OmniDocBench terms are not silently treated as commercial clearance.
Darmm is a synthetic source; Wikipedia text and individual font obligations need
resolution separately from its Apache dataset-card declaration.

Only individually accessible, legally eligible assets or publisher-authorized
bounded subsets may be admitted. There is no full-archive downloader, remote
dataset script execution, model download or upload in these tools. The metadata
acquisition used five public API responses capped at 2 MiB each and five cards
capped at 256 KiB each; all local originals stayed on the host.

Before content inspection, rank unique source record IDs by SHA-256 over the
canonical `[seed, dataset, record_id]` JSON. `selected_ids` and `selection_ledger`
retain deterministic selection and outside-budget exclusions. Sample records
retain attempted/admitted/rejected/unavailable/excluded dispositions and reasons.
Known source IDs that fail retrieval remain records, rather than replacement
draws. No unidentified hypothetical sample is counted as an attempted page.

Every obtained asset has exact SHA-256, size, format and a confined relative
path. JSON duplicate keys, path traversal, symlinks/junctions, changed files,
bad signatures, incorrect source/annotation bindings and page identities fail
closed. Original PDF page number and the page's number in a one-page derivative
are different fields. Annotations retain type, revision, coordinate convention,
origin and actual review provenance. Unknown labels remain unknown.

Family components join family IDs, related versions/translations, original-byte
hashes, normalized-text hashes and declared near-duplicate groups across dataset
boundaries. All admitted members of one component must share a split. The seeded
80/10/10 policy is a sampling rule, not an approved quality threshold. Unknown
family review keeps samples in development. Exposed benchmarks cannot become
new sealed tests; sealed tests require family-review provenance. A token-shingle
Jaccard threshold of 0.9 is diagnostic only; translations, short/changed/scanned
documents and template family completeness still need review. Short identical
normalized text is also flagged. Missing family completeness never yields QG PASS.

The existing 90 documents may be imported as `legacy_control`, all `dev`, with
opaque v2 IDs and immutable references to v1 bytes. They count toward **none** of
the seven new sampling targets. Original language labels, including Welsh, stay
intact. Existing source-page grouping is conservative and explicitly incomplete.
No additional RU/KK, DOCX or XLSX coverage is inferred from these controls.

## EX-01 geometry

`dataset_adapters_v2.doclaynet` consumes a bounded local COCO subset, its hashed
auxiliary JSON, corresponding PNG and original PDF. It checks image ID, PDF/PNG
stem, original filename/page metadata, actual image dimensions and original PDF
MediaBox/CropBox/rotation. Coordinates account for nonzero origins, independent
x/y scaling and rotations 0/90/180/270. Non-unit UserUnit is unsupported. The
image frame (`media` or `crop`) must be explicit; unsupported publisher boxes
outside the image are reported, never silently clamped. Redundant precedence
annotations and unknown classes remain unsupported. Auxiliary text agreement is
automatic-reference presence, not reviewed recall or semantic alignment.

`geometry_v2` creates a private self-contained PNG/region HTML overlay, a copy of
the original PDF, discrepancy JSON and an unsigned manual checklist. Creating
this packet does not perform human verification. Synthetic round-trip/pair tests
do not count as DocLayNet pages or representative layout coverage.

## EX-02 baseline and measurement

`extraction_v2 baseline` freezes input manifest/Gold bytes, native parser/scorer
code, dependency inventory, executable, configuration and environment before
running two serial passes in fresh child processes. It invokes the unchanged
production-native parser, including pypdf for PDFs. Default native parser limits
are preserved. Additional offline budgets: 60 seconds/document, sampled 1 GiB
process-tree RSS, 256 MiB scratch, one worker, 20 ms monitoring. These are task
budgets, not approved quality thresholds or an OS security sandbox.

Private raw captures and resource journals remain under ignored
`evaluation-output/`. Sanitized JSON/CSV contain opaque identities, states,
denominators, source output fingerprints, warnings and slices by format,
language, family, difficulty and cohort. Timing includes child startup and native
extraction; OS caches are not reset. P50/P95 use nearest rank. RSS sampling may
miss short peaks and sum shared pages. VRAM is unknown/not used for CPU native
runs. Runtime fields alone are removed for full repeated-report comparison.
Pins and input integrity are rechecked after execution.

Existing 19-record v1 Fidelity Gold can be scored only as a separately named
**legacy review attestation**, not new independent v2 Gold. Its existing scorer
semantics are retained; the additional exact numeric-bearing anchor check uses
literal Unicode/token boundaries without sign, zero or decimal normalization.
It does not exhaustively measure all numerical content. Failed/unavailable
captures retain expected label denominators and unobserved counts. New pilot
annotations are not silently scored as legacy Gold. New independent metrics
remain NOT_EVALUATED when independent labels are absent.

The additional Office pilot reuses the existing GOV.UK/OGL acquisition policy.
First inspect the 50 existing Office source pages; 49 pass the bounded metadata,
footer and alternative-rights checks, one exceeds the 1 MiB response cap. An
additional `q=xlsx&count=20&fields=link` Search API response yields 18 previously
unseen source pages, checked by the same policy. Preserve all responses/hashes.
The candidate pool has 340 initial unique Office URLs, then 16 supplemental XLSX
entries. Exclude v1 URLs and exact bytes. Rank remaining URLs by
`SHA256(seed + newline + format + newline + URL)` with seed `extraction-v2-office-1`.
Revision 1 limits each source-page/format to two attachments (16 DOCX, 24 XLSX).
Revision 2 expands the frozen metadata to fill the remaining minimum quotas
(14 DOCX, six XLSX), before inspecting any parser results. Each file is capped at
2 MiB and total payload at 30 MiB. No statistical adequacy is inferred from this
metadata-only, purposive sample. All 60 payload attempts were admitted; all
outside-selection and duplicate-v1 URL exclusions remain in the local ledgers.

`office_corpus_v2` rebuilds the pilot without network access, verifying frozen
page/attachment bindings, rights evidence, byte integrity, budgets and duplicate
exclusion against v1. Its public manifest contains 60 actual source identities,
not historical controls. Content language, fidelity, family completeness and
independent Gold remain unknown. All samples stay development-only. Attribution:
"Contains public sector information licensed under the Open Government Licence v3.0."

## EX-03/EX-04/EX-07 comparisons

`comparison_v2` provides diagnostic one-to-one class/page/box IoU comparison,
exact cell topology/literal precision/recall/F1 and complete-page paired anchor
guardrails. Region scores do not establish reading order. Its diagnostic IoU
setting is not COCO mAP or an approved acceptance threshold. GriTS/TEDS are
explicitly NOT_EVALUATED rather than approximated by a different formula.

PubTables/FinTabNet.c adapters preserve automatic-reference text, empty cells,
row/column spans and unknown relationships. Their publisher PyMuPDF top-left
coordinates are labelled as such, not fabricated native PDF user-space locators.
Source identity/conversion needs a verified original pair. OmniDocBench retains
polygons, order and ignore flags without converting raster-derived PDFs into
native text evidence. Darmm preserves tier/level/label and synthetic provenance.

Reuse `table_comparison.py`, `evidence_v2.py` and `hybrid_pdf.py` for pinned,
isolated captures and reviewed additive evidence. No production import is added.
There is no qualified new layout or TSR experiment when source rights, original
pairs, supported reference dimensions or independently reviewed evaluation are
missing. Unexecuted candidates are NOT_EVALUATED, never REJECT. Historical frozen
rejections are controls, not fresh current-HEAD results. No combined production
pipeline is created when its predecessor stages have not qualified.

## EX-05 source support hypothesis and guards

H1, registered here before the new real alignment runs: the existing independent
source-ruling/glyph reread can be reproduced while an added global ownership audit
refuses duplicate glyph assignments and literal/numeric conflicts. This tests
machine evidence mechanics, not new human Gold or model superiority.

`source_alignment_v2` reuses `pdf_cell_recovery`, with original SHA/page checks,
physical rulings, bounded complete logical grids and actual PDFium glyph ranges.
It checks every glyph's identity, mapping, geometry, angle, contiguous ownership
and reuse across all proposed tables. It never joins unrelated parser words.
Generated whitespace, missing glyphs, incomplete/uncertain boundaries and
unsupported transforms remain needs_review. Empty cells are unknown, not invented
empty-value proof. Header/unit/period relationships and calibrated confidence
remain unknown. Exact source-supported numeric conflicts reject that frozen
proposal, without turning a machine observation into reviewed quality PASS.

Run real proposals twice, retain private observations, compare every deterministic
field, and report supported/needs_review/conflict/duplicate counts. Engine/library
and recovery/alignment code hashes are recorded. Successful machine support still
does not authorize an evidence merge or independent Gold claim.

## EX-06 selective OCR hypothesis and guards

H2, registered here before the new OCR runs: the already implemented native-first
English OCR configuration can reproduce selected legacy-anchor recovery without
losing native observations. This is exposed development-control measurement.
The historical ML-18 gate is not a newly approved general QG threshold.

Use existing `tools.pdf_ocr_candidate.benchmark`: four historical pilot PDF IDs,
English only, 300 DPI, OEM 1, PSM 3, one thread, native-page low-text selector,
blank-render skip, existing limits (600 seconds/document, 3 GiB sampled process
tree, 256 MiB scratch, 40 pages/document, at most 10 OCR pages). Freeze a fresh
registration and actual engine/renderer/language artifact pins, then run twice.
Stop/retain timeouts, resource failures, corrupt outputs and text regressions.
No native observation is silently overwritten or enabled globally.

`ocr_diagnostics_v2` distinguishes provisional scan, encoding-risk, mixed-resource,
native-text and unknown routes. Nested form images, visible ink and CMap semantic
correctness remain unsupported. Its literal CER/WER calculator reports edit
numerators/denominators, exact numeric changes/additions, required anchors and
Kazakh letter coverage by language and reference class. CER/WER require reviewed
full transcripts; legacy selected anchors do not supply them. RU/KK synthetic
tests and Darmm are not real RU/KK quality evidence. Existing OCR enrichment
observations stay separate; absent RU/KK traineddata and Gold block those cohorts.

## Engineering review and captured-evidence reconciliation

The follow-up milestone reviews these same 19 files and reuses saved observations;
it does not repeat extraction/OCR/model experiments. Original code/pins/results stay
historical. Current guards are verified with synthetic regression cases and frozen
source-capture replay; they do not retroactively relabel old runs as current-code runs.
Annotation JSON payloads and coordinate bases must match their declared kind;
publisher PyMuPDF top-left table annotations cannot claim native PDF user space.
Confirmed page-identity mismatch is QG-00 FAIL, distinct from unavailable inputs.
Machine glyph support is not semantic relationship verification. Synthetic/legacy
cohorts cannot count as new real-document independent Gold even with supplied review.
Duplicate source-record/page identities are rejected; multiple distinct members of
one family are valid and must retain a common split.

OCR diagnostics require the same rights/disposition/asset eligibility checks as the
native runner, keep failures visible and return BLOCKED on incomplete diagnostics.
Unknown cell text cannot earn exact-text F1; empty known strings remain valid. Table
page indices/boxes and image dimensions must be valid independently of cell presence.
Alignment fingerprints now bind the source, complete cell/native observations,
candidate identity and numeric-tokenizer source hash; confidence/semantics remain unknown.

`extraction_v2 verify-results --results <JSON> --csv <CSV>` validates the delivered
fingerprint, lossless projection (including empty objects), full native cohorts/two
repetitions, summaries/slices and basic alignment/OCR accounting. It does not certify
source authenticity; the separate local audit reconciles all 300 saved native
captures and original bytes without new extraction. Report quality gates remain
NOT_EVALUATED and production release NOT AUTHORIZED even when engineering is PASS.
